# 🚗 Sistema de Gestão de Consórcios

## 📖 Sobre o Projeto

O Sistema de Gestão de Consórcios foi desenvolvido com o objetivo de auxiliar no gerenciamento de clientes, veículos, grupos de consórcio e cotas de forma simples, organizada e eficiente.

O projeto simula o funcionamento de uma administradora de consórcios, permitindo o cadastro e controle das principais informações necessárias para a administração de grupos e venda de cotas.

A proposta é centralizar os dados em uma única plataforma, facilitando o acompanhamento das operações e reduzindo processos manuais. Com isso, é possível cadastrar clientes, associá-los a grupos específicos, cadastrar veículos, criar grupos de consórcio e efetuar a venda de cotas de maneira rápida e segura.

Além da parte funcional, o projeto foi desenvolvido aplicando conceitos de Programação Orientada a Objetos (POO), desenvolvimento web e metodologias ágeis, proporcionando uma experiência próxima à realidade do mercado de tecnologia.

---

## 🎯 Objetivo do Projeto

A ideia principal surgiu da necessidade de controlar informações relacionadas a consórcios de veículos de forma digital.

Em muitos cenários, esse controle é realizado por meio de planilhas ou processos manuais, dificultando consultas, manutenção dos dados e aumentando a possibilidade de erros.

O sistema foi projetado para:

* 👤 Cadastrar clientes participantes dos grupos de consórcio;
* 🚗 Cadastrar veículos disponíveis para formação dos grupos;
* 📋 Criar grupos de consórcio com diferentes prazos e quantidades de cotas;
* 💰 Calcular automaticamente as taxas administrativas conforme a quantidade de parcelas;
* 📄 Gerenciar a venda de cotas para clientes;
* 📊 Consultar informações através de uma interface web intuitiva;
* 🗑️ Excluir registros quando necessário.
