# CONSORCIO_FECAF
#Sistema de Gestão de Consórcios
Introdução

O Sistema de Gestão de Consórcios foi desenvolvido com o objetivo de auxiliar no gerenciamento de clientes, veículos, grupos de consórcio e cotas de forma simples, organizada e eficiente. O projeto simula o funcionamento de uma empresa de consórcios, permitindo o cadastro e controle das principais informações necessárias para a administração de grupos e vendas de cotas.

A proposta do sistema é centralizar os dados em uma única plataforma, facilitando o acompanhamento das operações e reduzindo processos manuais. Com isso, é possível realizar o cadastro de clientes, associá-los a grupos específicos, cadastrar veículos, criar grupos de consórcio com diferentes quantidades de parcelas e efetuar a venda de cotas de maneira rápida e segura.

Além da parte funcional, o projeto foi desenvolvido aplicando conceitos de programação orientada a objetos, desenvolvimento web e organização de projetos utilizando metodologias ágeis, permitindo uma experiência próxima à realidade encontrada no mercado de tecnologia.

#Ideia do Projeto

A ideia principal do projeto surgiu da necessidade de controlar informações relacionadas a consórcios de veículos de forma digital. Em muitas situações, esse controle é realizado através de planilhas ou processos manuais, dificultando consultas e aumentando a possibilidade de erros.

#O sistema foi projetado para:

Cadastrar clientes participantes dos grupos de consórcio;
Cadastrar veículos disponíveis para formação dos grupos;
Criar grupos de consórcio com diferentes prazos e quantidades de cotas;
Calcular automaticamente as taxas administrativas conforme a quantidade de parcelas;
Gerenciar a venda de cotas para clientes;
Consultar informações de forma organizada através de uma interface web moderna;
Excluir registros quando necessário.

Dessa forma, o sistema oferece uma solução simples para o gerenciamento de consórcios, simulando operações reais realizadas por administradoras do setor.

#Conclusão

O Sistema de Gestão de Consórcios permitiu aplicar na prática conceitos estudados durante o curso, integrando desenvolvimento web, banco de dados, programação orientada a objetos e metodologias ágeis. O resultado é uma aplicação funcional capaz de gerenciar clientes, veículos, grupos e cotas de consórcio de forma organizada, servindo como uma solução acadêmica que simula um cenário real de mercado.
